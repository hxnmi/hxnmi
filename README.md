## What I do

- **Gameplay in Unity**: 2D and 3D mechanics, camera and UI work, shaders, and editor tooling across Unity 2021 LTS through Unity 6.
- **Game AI**: reinforcement learning agents trained with Unity ML-Agents (PPO), plus LLM-driven NPC dialogue.
- **Product tooling**: TypeScript and Next.js apps, and Cloudflare Workers services that support the games and communities around them.
